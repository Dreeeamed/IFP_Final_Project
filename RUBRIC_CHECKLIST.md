## What to do before the defense to turn "Partly" into "Met"

1. Run the manual checklist rows marked ☐ in TESTING.md on Firefox, Safari/iOS and an Android phone; record results.
2. Do a keyboard-only and a screen-reader (NVDA/VoiceOver) pass; fix anything found.
3. Build the slides from `docs/PRESENTATION_OUTLINE.md` with real screenshots; rehearse the demo twice with a timer.
4. Optional: add a simple load test (e.g. 200 SignalR clients with a small console app) and record the numbers.
5. Optional: add bUnit tests for `WordBoard`/`VirtualKeyboard` and a Playwright smoke test.
